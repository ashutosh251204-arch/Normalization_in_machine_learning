# Normalization_in_machine_learning
Normalization (jise Machine Learning mein Min-Max Scaling bhi kaha jata hai) ek preprocessing technique hai jisme hum numerical features ko rescales karke ek fixed range—amtaur par 0 se 1 ke beech—mein le aate hain.
Normalization ka formula har data point $x$ ke liye yeh hota hai:
Xnew = x - x_min/ x_max - x_min
x = Original value
x_min = Feature column ki sabse chhoti value (Minimum value)
Xnew = Scaled value (jo 0 aur 1 ke beech aayegi)
